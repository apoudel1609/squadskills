⚡ Squad Setup

This app stores data on JSONBin.io — free JSON cloud storage. One person does this setup and shares the credentials with the group.

Setup (2 min):
1. Go to jsonbin.io → Sign up free
2. Click Create a Bin → paste the JSON below into the content field:

{"squad":"skills-matrix","members":{}}

3. Hit Save → copy the Bin ID from the URL or sidebar
4. Go to API Keys → copy your Master Key
5. Paste both below and share with the squad
